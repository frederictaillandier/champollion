Learning Czech from Kingdom Come: Deliverance II

Champollion

A set of Rust tools that watches you play a game in Czech, reads the words on screen, turns the new ones into flashcards, and closes the game when it's time to review them. You only learn words you actually met while playing.

The loop

From a word on screen to a word you know

  1. You play.The daemon on the desktop sees the game start and records the screen to 2-minute video files, encoded on the graphics card's separate video chip.
  2. The text is read.Each finished file is sent to a Jetson board on the home network, which reads it on its GPU, so the game keeps the whole PC.
  3. Lines are corrected.On the Jetson too, each line read is matched against the game's own Czech text, so misread accents come back exact.
  4. New words become cards.Claude turns new words into flashcards: dictionary form, translation, meaning in that sentence, and the sentence itself.
  5. You review on your phone.A home-screen widget shows the cards due, spaced out like Anki, with the word spoken.
  6. The game waits for you.When 50 cards are due, the daemon closes the game, and keeps it closed until fewer than 10 are.
