Phone widget

Reviews happen in a flashcard widget, written in Kotlin with Jetpack Glance, on the phone's home screen, and on a Galaxy Z Flip's cover screen too. It works offline. Since 16 October it runs on a Galaxy A17.

A review

Front, then back

The front shows the word and the game sentence it was read in. A tap turns it: the translation, its meaning in that sentence, and the sentence's translation, with Failed and Succeed. ⚑ flags a wrong card: it leaves the reviews and is kept on the backend to be fixed. ↩ takes back the last rating or flag, a misclick, as long as it hasn't been sent.

Each time a rating or a flag shows the next card, its word is spoken: the backend's ElevenLabs recording, downloaded with the session so it plays offline too. The first card of a session stays silent. 🔊 under the word plays it again; 🔊 next to ⚑ mutes the words.

Offline

A session of 50 cards, synced when it can

The backend is only reachable with the phone's WireGuard tunnel on, so the widget never waits for it. It downloads a whole session, keeps the ratings and flags in a DataStore, and sends them later.

Two places

Home screen, and the Flip's cover screen

The same widget comes in two versions sharing one session: one for the home screen, and one for the Galaxy Z Flip's cover screen (Flex Window). Samsung requires the latter to be a keyguard widget of at least 352×339 dp, declaring display="sub_screen" in a com.samsung.android.appwidget.provider entry.

cd android
./gradlew installDebug      # phone plugged in, USB debugging on

Then tap the Champollion icon: it syncs, and asks the launcher to add the widget. For the cover screen: Settings → Cover screen → Widgets → Flashcards.

A new phone

Moving to another phone

How the widget moved from the Galaxy Z Flip to a Galaxy A17 on 16 October. The reviews themselves live on the backend, so nothing else needs copying.

  1. Turn on developer modeSettings → About phone → Software information → tap Build number 7 times. Then Settings → Developer options → USB debugging.
  2. Plug it in and allow the PCAccept "Allow USB debugging?", with "Always allow from this computer". adb devices should list it as device, not unauthorized.
  3. Install the appcd android && ./gradlew installDebug (26 seconds).
  4. Bring the WireGuard tunnel overOn the old phone: WireGuard → ⋮ → Settings → Export tunnels, which saves a zip in Downloads. Copy it to the new phone (adb pull, then adb push), and import it there with + → Import from file or archive. Then delete the zip on both: it holds the tunnel's private key.
  5. Turn the tunnel off on the old phoneBoth phones now share one key and one address, 10.0.0.51; connected at once, they knock each other off.
